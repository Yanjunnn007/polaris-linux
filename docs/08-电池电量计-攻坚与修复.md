# 小米 MIX 2S (polaris) PMI8998 电池库仑计/电量计修复记录

> **日期**: 2026-10-13  
> **机型**: 小米 MIX 2S (`polaris`)  
> **SoC/PMIC**: 高通骁龙 845 (`SDM845`) / `PM8998` + `PMI8998`  
> **内核版本**: `Linux 7.1.0-rc1-sdm845` (`boot-r28.img` / 构建 #29)  
> **相关补丁**: `patches/0010-arm64-dts-sdm845-polaris-battery-fg.patch`

---

## 一、 故障现象

在 postmarketOS Phosh 桌面环境下，用户发现手机顶部状态栏**无法显示当前电池电量百分比**，甚至显示电池缺失图标。

通过 SSH 远程排查系统的电源与电量管理层：
1. **sysfs 节点缺失**：
   ```bash
   ls /sys/class/power_supply/
   # 仅存在:
   # pmi8998-charger -> 充电适配器/USB供电节点 (type=USB)
   # tcpm-source-psy-... -> Type-C TCPM 节点
   # 完全没有电池设备 (battery / qcom-battery)
   ```
2. **UPower 守护进程状态**：
   ```bash
   upower -d
   # Device: /org/freedesktop/UPower/devices/DisplayDevice
   #   percentage: 0%
   #   icon-name: 'battery-missing-symbolic'
   ```
由于没有暴露标准的 `power_supply` 电池子系统节点，UPower 无法获取电池数据，导致 GNOME / Phosh 桌面顶栏无法显示电量与充放电状态。

---

## 二、 根因排查与硬件拓扑

### 1. 电源管理芯片架构
小米 MIX 2S 采用高通经典的双 PMIC 架构：
- **主 PMIC**: `PM8998`（主要负责核心供电、时钟、GPIO、震动马达等）
- **从 PMIC / 充放电管理芯片**: `PMI8998`（挂载于 SPMI 总线地址 2 / 3），内部集成两大核心模块：
  - `charger@1000`：Qualcomm SMB1381 / PMI8998 开关充电与 Type-C 控制器。
  - `fuel-gauge@4000`：Qualcomm PMI8998 Fuel Gauge 硬件库仑计/电量计，负责采集锂电池单体开路电压 (OCV)、充放电积分库仑电量、瞬时充放电电流、电芯温度。

### 2. 驱动与设备树审计
1. **驱动层面**：
   - 内核配置 `CONFIG_BATTERY_PMI8998_FG=m` 已经开启。
   - 驱动模块文件 `/lib/modules/7.1.0-rc1-sdm845/kernel/drivers/power/supply/pmi8998_fg.ko.zst` 存在于系统内，驱动源码 `drivers/power/supply/pmi8998_fg.c` 兼容 `qcom,pmi8998-fg`。
2. **设备树层面**：
   - 查看上游公共定义 `arch/arm64/boot/dts/qcom/pmi8998.dtsi`：
     ```dts
     pmi8998_fg: fuel-gauge@4000 {
         compatible = "qcom,pmi8998-fg";
         reg = <0x4000>;
         interrupts = <0x2 0x40 0x0 IRQ_TYPE_EDGE_RISING>,
                      ...;
         status = "disabled";
     };
     ```
     公共 dtsi 中电量计节点默认声明为 **`status = "disabled";`**。
   - 查看机型设备树 `arch/arm64/boot/dts/qcom/sdm845-xiaomi-polaris.dts`：
     - 已有单体锂电池规格定义：
       ```dts
       battery: battery {
           compatible = "simple-battery";
           charge-full-design-microamp-hours = <3400000>; /* 小米MIX 2S原厂BM3B电池 3400mAh */
           voltage-min-design-microvolt = <3400000>;
           voltage-max-design-microvolt = <4400000>;
       };
       ```
     - 已启用充电控制器：
       ```dts
       &pmi8998_charger {
           monitored-battery = <&battery>;
           status = "okay";
       };
       ```
     - **致命遗漏**：设备树中完全**没有**引用并启用 `&pmi8998_fg`！导致该硬件模块一直处于 disabled 状态，内核没有探测到电量计，模块从未被自动拉起。

---

## 三、 补丁实现

为 `arch/arm64/boot/dts/qcom/sdm845-xiaomi-polaris.dts` 编写补丁，挂载并激活 `pmi8998_fg`，并将其与 `pmi8998_charger` 及 `battery` 进行双向关联：

```dts
--- a/arch/arm64/boot/dts/qcom/sdm845-xiaomi-polaris.dts
+++ b/arch/arm64/boot/dts/qcom/sdm845-xiaomi-polaris.dts
@@ -610,6 +610,12 @@
 &pmi8998_charger {
 	monitored-battery = <&battery>;
 	status = "okay";
 };
+
+&pmi8998_fg {
+	power-supplies = <&pmi8998_charger>;
+	monitored-battery = <&battery>;
+	status = "okay";
+};
 
 &pmi8998_lsid0 {
```

- `power-supplies = <&pmi8998_charger>`：告知电量计其供电输入源为 PMI8998 充电器，以便感知外接供电状态。
- `monitored-battery = <&battery>`：绑定极性与 3400mAh 额定容量规格。
- `status = "okay"`：覆盖 dtsi 默认的 disabled 状态，触发内核 SPMI 总线自动 probe。

## 四、 编译与免按键系统内刷写

1. **打包与编译**：
   - 在 pmaports 的 `linux-postmarketos-qcom-sdm845/APKBUILD` 中将 `pkgrel` 递增至 `28`，增加 `sdm845-polaris-battery.patch`。
   - 触发增量编译：
     ```bash
     pmbootstrap build linux-postmarketos-qcom-sdm845 --force
     pmbootstrap export /mnt/c/pmos
     ```
   - 导出生成 `boot-r28.img` 与 `modules-r28.tar.gz`。

2. **在系统内直接写入（免 Fastboot 手动操作）**：
   无需将手机关机进入 Fastboot，通过已有 SSH 通道直接将镜像写入 boot 分区并同步驱动模块：
   ```bash
   scp boot-r28.img modules-r28.tar.gz user@172.16.42.1:/home/user/
   ssh user@172.16.42.1 "echo pmos | sudo -S tar -xzf /home/user/modules-r28.tar.gz -C /lib/modules/ && \
                        echo pmos | sudo -S dd if=/home/user/boot-r28.img of=/dev/disk/by-partlabel/boot bs=4M conv=fsync && \
                        echo pmos | sudo -S reboot"
   ```

## 五、 实测验证结果

### 1. 内核 Sysfs 节点采集
重启后，`pmi8998_fg` 驱动自动匹配并加载成功，在 `/sys/class/power_supply/` 下生成 `qcom-battery` 节点：

```bash
$ cat /sys/class/power_supply/qcom-battery/uevent
DEVTYPE=power_supply
OF_NAME=fuel-gauge
OF_FULLNAME=/soc@0/spmi@c440000/pmic@2/fuel-gauge@4000
OF_COMPATIBLE_0=qcom,pmi8998-fg
OF_COMPATIBLE_N=1
POWER_SUPPLY_NAME=qcom-battery
POWER_SUPPLY_TYPE=Battery
POWER_SUPPLY_STATUS=Full
POWER_SUPPLY_PRESENT=1
POWER_SUPPLY_TECHNOLOGY=Li-ion
POWER_SUPPLY_VOLTAGE_MAX_DESIGN=4400000
POWER_SUPPLY_VOLTAGE_MIN_DESIGN=3400000
POWER_SUPPLY_VOLTAGE_NOW=4162098            # 实时电芯电压 4.162 V
POWER_SUPPLY_CURRENT_NOW=-881835           # 充放电实时电流
POWER_SUPPLY_CHARGE_FULL_DESIGN=3400000    # 设计容量 3400 mAh
POWER_SUPPLY_CAPACITY=99                   # 精准剩余百分比: 99%
POWER_SUPPLY_TEMP=313                      # 电池温度: 31.3 °C
POWER_SUPPLY_TEMP_MAX=600
POWER_SUPPLY_TEMP_MIN=0
POWER_SUPPLY_TEMP_ALERT_MIN=100
POWER_SUPPLY_TEMP_ALERT_MAX=450
```
