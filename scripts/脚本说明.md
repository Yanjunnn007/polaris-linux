# 工具脚本说明

这些脚本在移植与调试过程中实际使用，按用途分类归档。

---

## 一、 音频与外放管理（第五阶段新增）

| 脚本 | 运行位置 | 用途与特性 |
|---|---|---|
| **`setup_audio.sh`** | 手机端 (`/home/user` / `/usr/local/bin`) | **一键声卡与外放激活脚本**：建立 ALSA UCM2 拓扑符号链接，重载 UCM HiFi / 扬声器模式，打通 Qualcomm QDSP6 MI2S 路由总线，将 PulseAudio 默认 Sink 绑定至 TI TAS2560 外放扬声器并固化配置。 |

---

## 二、 相机拍照与图像解算（第四阶段新增）

| 脚本 | 运行位置 | 用途与特性 |
|---|---|---|
| **`polaris-focus`** | 手机端 (`/usr/local/bin`) / 工具包 | **VCM 音圈马达调焦工具**：控制 AK7372 12-bit DAC（范围 0~4095），支持别名 `inf`（无限远/风景）、`mid`（中景 1~2m）、`close`（近景 30~50cm）、`macro`（极限微距 5~10cm）及任意数值调焦。 |
| **`take_photo.py`** | PC 端 (Windows) | **全自动一键拍照与调焦**：支持参数 `--focus <值>`，通过 SSH 触发手机端硬件抓帧，自动拉取 15.24MB RAW10 镜像到 PC，执行软件 ISP 矩阵计算并输出高清全彩 `shot.png`。 |
| **`process_raw.py`** | PC 端 (Windows) | **离线 RAW10 软件 ISP 解包器**：实现 10-bit MIPI 5-byte 解压、扣除索尼原厂暗电流黑电平 64、BGGR 拜耳滤镜解马赛克、动态范围自适应映射，输出 PNG。 |
| **`polaris-cam-setup`** | 手机端 (`/usr/local/bin`) | **一键相机链路拓扑**：配置 `media-ctl` 全链路路由（IMX363 $\rightarrow$ CSIPHY0 $\rightarrow$ CSID0 $\rightarrow$ VFE0 RDI0）与 4032×3024 SBGGR10 格式。 |
| **`polaris-cam-shoot`** | 手机端 (`/usr/local/bin`) | **一键硬件抓帧**：自动注入曝光行数与模拟增益，跳过前 5 帧使积分稳定，单帧捕获落盘至 `/tmp/shot.raw`。 |

## 三、 Type-C 与 OTG 调试（第三阶段新增）

| 脚本 | 运行位置 | 用途 |
|---|---|---|
| `switch_otg_host.sh` | 手机端 | 手动将 DWC3 切换为 Host 模式并开启 VBUS 供电（用于 Phase 2 手动调试验证）。 |
| `switch_otg_device.sh` | 手机端 | 手动将 DWC3 切回 Device 模式，恢复 USB-NCM 从机网卡与充电。 |
| `otg_hub_test.sh` | 手机端 | 监听 USB 外设枚举事件，测试无源 HUB 与键鼠识别情况。 |

---

## 四、 TWRP / 刷机与备份

| 脚本 | 用途 |
|---|---|
| `dobackup.sh` | TWRP 里备份 polaris 全部分区到 `/sdcard/polaris_backup/`（救砖保障）。 |
| `twrp_gpt.sh` | TWRP 里解析 sda21 的 GPT，验证 rootfs 是否写对（EFI PART 签名 + 条目 GUID）。 |
| `twrp_verify.sh` | TWRP 里用 losetup 挂子分区验证 UUID。 |

---

## 五、 串口调试（pmOS 起来后，COM5）

| 脚本 | 用途 |
|---|---|
| `ser_listen.py` / `ser_bootwatch.py` | 监听串口输出一段时间（抓内核/initramfs 日志）。 |
| `ser_dmesg.py` | 通过串口读 dmesg 关键行（loop/mount/ext4）。 |
| `ser_panel.py` | 查 panel/DSI/DRM/backlight 相关 dmesg。 |
| `ser_login.py` | 尝试串口登录进系统（user + 密码）。 |
| `ser_read.py` | 通用串口读写。 |

> 提示：串口回显常不可靠（只回命令本身），更靠谱的是看 PMOS_LOGS 盘里的 `dmesg.txt`。
